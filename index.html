⚡ 什麼是 Live API？ (Multimodal Live API)

Live API 是 Google 推出的基於 WebSocket 協議 的雙向低延遲對話接口（類似 Gemini Live 音訊體驗），允許使用者直接傳輸連續語音/視訊流並獲得極速語音回應。

🔍 什麼是 Grounding (搜尋與地圖接地)？

Grounding 代表模型具備連結 Google Web 即時搜尋 或 Google Maps 地理資料庫 的能力，讓回答不再侷限於模型訓練截止日，自動附帶最新實時出處網址。

⚠️ 圖像生成 (Imagen / Nano Banana) 綁卡說明

Google 官方規定圖像與影音生成 endpoints (Imagen 3 / Veo) 必須在 GCP 專案上繫結 Pay-As-You-Go 結算帳戶 (信用卡)。純免費未綁卡專案發送請求會返回 403 Billing 錯誤。

額度限額名詞說明
RPM
Requests Per Minute
每分鐘最多可發送的 API 請求次數限制。
TPM
Tokens Per Minute
每分鐘最多可傳輸的總 Token 數限制（包含輸入與輸出）。
RPD
Requests Per Day
每日最多可發送的 API 總請求次數上限 (RPD > 0 代表免費模型)。
