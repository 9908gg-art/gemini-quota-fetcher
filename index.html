📜 跨版本動態評分標準與演算邏輯 (Future-Proof Rating Engine)

本站拋棄靜態硬編碼評分，採用客觀的版本與能力演算法 (Dynamic Version-Aware Engine)。評分直接根據 API 英文名稱中的代際版本號（1.5 / 2.5 / 3.0 / 3.5 / 4.0 / 5.0...）與能力後綴動態計算，確保未來推出 Gemini 4.0 或 5.0 時依然能準確且客觀地自動計分：

1. 代際版本基礎分 (Base Score)
算式：7.5 + (Major_Version * 0.5)
例如：Ver 2.5 = 8.8 分，Ver 3.5 = 9.25 分，Ver 4.0 = 9.5 分，Ver 5.0 = 9.9 分。
2. 核心推理與級別加分 (+0.5)
具有 Pro、Ultra 或 Thinking 旗艦標籤模型享有 +0.5 深度推理加分。
3. 速度與極速輕量 (+0.3)
Flash 高速平衡模型享 +0.3 加分，Flash-Lite 享 +0.1 加分。
4. 實時擴充與串流 (+0.2)
Live API 雙向對話與 Grounding 實時搜尋接地享 +0.2 功能加分。
⚡ 什麼是 Live API？ (Multimodal Live API)

Live API 是 Google 推出的基於 WebSocket 協議 的雙向低延遲對話接口（類似 Gemini Live 語音體驗）。它允許應用程式建立持久長連接，直接將連續音訊/視訊串流傳送給模型並獲得實時極速回應。

🌐 什麼是 實時網路搜尋與地圖引註 (Grounding)？

Grounding 並非獨立模型，而是代表模型具備連結 Google Web 即時搜尋 或 Google Maps 地理數據庫 的實時檢索能力。完全支援日常對話與文字創作，並在此基礎上自動檢索實時網頁與出處連結。

⚠️ 圖像與影音生成 (Imagen / Veo) 綁卡說明

Google 官方規定所有圖像與影音生成 endpoints (Imagen 3 / Veo) 必須在 GCP 專案上繫結 Pay-As-You-Go 結算帳戶 (信用卡) 方可呼叫。純免費未綁卡專案發送請求會強制返回 HTTP 403 Billing 錯誤。

提供結構化的 JSON 數據接口 (`gemini_rate_limits.json`)，內含 `_developer_guide` 說明。您的語音輸入工具或 AI 軟體可直接讀取陣列的第一個元素 (Index 0) 作為預設首選最佳模型。
故障切換與自動降級 (Failover)
當您的工具呼叫當前模型遇到 HTTP 429 額度超限時，順序存取下一個 `is_free_tier: true` 的模型即可實現 100% 不中斷自動降級與備援。
額度限額名詞說明 (RPM / TPM / RPD)
RPM
Requests Per Minute
每分鐘最多可發送的 API 請求次數限制。
TPM
Tokens Per Minute
每分鐘最多可傳輸的總 Token 數限制（包含輸入與輸出）。
RPD
Requests Per Day
每日最多可發送的 API 總請求次數上限。顯示 Unlimited 代表每日發送次數完全無上限。
Free vs Paid
Free / Pay-as-you-go
免費層級具有每日限制 (RPD > 0 或 Unlimited)；付費層級依量計費，無每日上限。
