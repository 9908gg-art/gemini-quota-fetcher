📜 模型綜合評分標準與排序算式說明

為了讓開發者一目了然地挑選最高 CP 值與最強大性能的模型，本站針對各模型進行 10.0 分制綜合評分，評分標準包含以下四大核心維度：

1. 模型代際與推理實力 (40%)
Gemini 3.5 / 3.1 Pro 擁有最強推理與邏輯實力，基礎分高達 9.5~9.8。
2. 每日免費上限 RPD (30%)
RPD ≥ 1500 次/日額度最高者額外獲得 +0.3 加分，確保適合工具長期調度。
3. 原生多模態能力 (20%)
具備圖片辨識、PDF 閱讀與截圖 OCR 的多模態模型享有更高綜合評分。
4. 響應速度 RPM (10%)
Flash 輕量系列響應極快且 RPM 限額高，享有速率調度權重加分。
⚡ 什麼是 Live API？ (Multimodal Live API)

Live API 是 Google 推出的基於 WebSocket 協議 的雙向低延遲對話接口（類似 Gemini Live 語音體驗）。它允許應用程式建立持久長連接，直接將連續音訊/視訊串流傳送給模型並獲得實時極速回應，適用於即時語音助手與視訊對話應用。

🌐 什麼是 實時網路搜尋與地圖引註 (Grounding)？

Grounding 並非獨立模型，而是代表模型具備連結 Google Web 即時搜尋 或 Google Maps 地理數據庫 的實時檢索能力。它讓 AI 的回答擺脫訓練截止日限制，回答時會自動附帶出處參考網址與實時地圖座標。

⚠️ 圖像與影音生成 (Imagen / Veo) 綁卡說明

Google 官方規定所有圖像與影音生成 endpoints (Imagen 3 / Veo) 必須在 GCP 專案上繫結 Pay-As-You-Go 結算帳戶 (信用卡) 方可呼叫。純免費未綁卡專案發送請求會強制返回 HTTP 403 Billing 錯誤。

額度限額名詞說明 (RPM / TPM / RPD)
RPM
Requests Per Minute
每分鐘最多可發送的 API 請求次數限制。
TPM
Tokens Per Minute
每分鐘最多可傳輸的總 Token 數限制（包含輸入與輸出）。
RPD
Requests Per Day
每日最多可發送的 API 總請求次數上限 (RPD > 0 代表免費模型)。
Free vs Paid
Free / Pay-as-you-go
免費層級具有每日限制 (RPD > 0)；付費層級依量計費，無每日上限。
